# PROYECTO: REDISEÑO COMPLETO DE LATAWEL
# ROL: OPENCode — Frontend Engineer + UI Engineer + Design System Implementer

Construye el rediseño completo de latawel.com utilizando el branding oficial de LATAWEL proporcionado por el proyecto.

NO crear una estética nueva independiente.
NO improvisar una nueva identidad.
NO reemplazar el sistema visual.
NO rediseñar el logo.

El objetivo es transformar la experiencia actual en una plataforma digital moderna, urbana, energética, accesible y orientada al descubrimiento.

============================================================
