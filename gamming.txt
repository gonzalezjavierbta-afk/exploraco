## 1. Análisis del Problema y Objetivos del Rediseño

Para que ExploraCO sea autosostenible, orgánico y vibrante, el sistema de incentivos debe resolver tres desafíos estructurales:

1. **Curva de Experiencia Progresiva (Level Scaling hasta x3.0):** La cantidad de XP otorgada por acción ya no es fija. Para motivar al usuario a subir de nivel y hacer que el avance sea gratificante, se implementa un **Multiplicador de Nivel** ($M_{\text{nivel}}$) que escala paso a paso desde **x1.0 en el Nivel 1** hasta alcanzar **x3.0 en el Nivel 20**.
2. **Prevención de Spam y Anti-Farming (Rising Star Decay System):** Las acciones repetitivas (como votar fotos masivamente o enviar mensajes vacíos) generan ruido en la base de datos. Se implementa una **curva de ráfaga con decaimiento por enfriamiento (Cooldown/Ramping Decay)** inspirada en *Rising Star*, donde el rendimiento de puntos disminuye hasta $0$ tras $N$ ejecuciones consecutivas dentro de una ventana temporal, restaurándose gradualmente.
3. **Nutrición Orgánica del Ecosistema (Mapa, Puntos y Planes):** El negocio requiere tres pilares para crecer:
   - **Puntos en el mapa (Geometría/Destinos):** Recompensar fuertemente la creación, verificación y completado de atributos en spots turísticos/ocultos.
   - **Usuarios alimentando el mapa (Comunidad/Wayfarers):** Recompensar fotos de calidad con coordenadas exactas, reseñas estructuradas y validación comunitaria.
   - **Medios que ayuden a alimentar estos recursos (Planes/Interactividad):** Convertir el mapa estático en rutas y agendas dinámicas donde la gente interactúe, asista y converse.

## 2. Nueva Fórmula General de Cálculo de XP Server-Side

Cada acción $A$ ejecutada por un usuario $u$ en un contexto $c$ generará experiencia según la fórmula:

$$\text{XP}_{\text{ganada}} = \text{BaseXP}(A) \times M_{\text{nivel}}(N) \times D_{\text{decay}}(A, u) \times M_{\text{contexto}}(c) \times M_{\text{casa}}(u)$$

---

### A. Multiplicador de Nivel ($M_{\text{nivel}}$) — Escala x1.0 a x3.0

Para motivar la progresión continua, subir de nivel incrementa progresivamente el retorno de XP en todas las actividades hasta duplicar el rendimiento base adicional en el Nivel 20 ($+200\% \rightarrow x3.0$):

$$M_{\text{nivel}}(N) = 1.0 + \left( \frac{N - 1}{19} \right) \times 2.0$$

Donde $N$ es el nivel actual del usuario ($1 \le N \le 20$).

### B. Curva Rising Star Decay ($D_{\text{decay}}$)

Las acciones altamente repetibles usan un contador de ráfaga en la base de datos dentro de una ventana temporal `ventanaMinutos`.

$$\text{Factor Decay } D(k) = \max\left(0, \ 1.0 - \left( \frac{k - 1}{K_{\text{max}} - 1} \right)^\alpha \right)$$

Donde $k$ es el número de repeticiones acumuladas en la ventana y $K_{\text{max}}$ es el límite de agotamiento.

| Acción | $K_{\text{max}}$ (Límite Ráfaga) | $\alpha$ (Curva) | Puntos x Ejecución en Ráfaga (Base=5) | Cooldown Total |
|---|---|---|---|---|
| **Votar Foto de Destino / Álbum** | 10 | 1.5 | $5 \rightarrow 4 \rightarrow 4 \rightarrow 3 \rightarrow 3 \rightarrow 2 \rightarrow 1 \rightarrow 1 \rightarrow 0 \rightarrow 0$ | 60 minutos |
| **Comentar Media / Mensaje Chat** | 8 | 1.0 | $2 \rightarrow 2 \rightarrow 1 \rightarrow 1 \rightarrow 1 \rightarrow 0 \rightarrow 0 \rightarrow 0$ | 30 minutos |
| **Check-in / Visita Confirmada** | 3 | 2.0 | $30 \rightarrow 22 \rightarrow 0$ | 120 minutos |

// Fragmento de calculo XP con Multiplicador Nivel (x1.0 a x3.0) y Rising Star Decay
// Archivo: api/interacciones.js

function obtenerMultiplicadorNivel(nivel) {
  var n = Math.max(1, Math.min(20, nivel || 1));
  return 1.0 + ((n - 1) / 19.0) * 2.0;
}

async function calcularExperienciaAccion(client, usuarioId, accion, nivelUsuario) {
  var basesXP = {
    'resena_larga': 40,
    'resena_corta': 10,
    'visita_confirmada': 30,
    'voto_foto': 5,
    'subir_foto': 25,
    'proponer_spot': 100,
    'completar_spot': 25,
    'crear_plan': 60,
    'unirse_plan': 15,
    'voto_wayfarer': 10
  };

  var limitesDecay = {
    'voto_foto': { kMax: 10, ventanaMinutos: 60, alpha: 1.5 },
    'comentar_media': { kMax: 8, ventanaMinutos: 30, alpha: 1.0 },
    'voto_wayfarer': { kMax: 15, ventanaMinutos: 60, alpha: 1.2 }
  };

  var xpBase = basesXP[accion] || 2;
  var factorDecay = 1.0;

  // Evaluacion de Decay si la accion es repetitiva
  if (limitesDecay[accion]) {
    var conf = limitesDecay[accion];
    var resDecay = await client.query(
      "SELECT conteo_rafaga, ultimo_evento FROM user_action_decay WHERE usuario_id = $1 AND accion = $2",
      [usuarioId, accion]
    );

    var ahora = new Date();
    var conteo = 1;

    if (resDecay.rows.length > 0) {
      var ultimo = new Date(resDecay.rows[0].ultimo_evento);
      var difMinutos = (ahora - ultimo) / (1000 * 60);

      if (difMinutos < conf.ventanaMinutos) {
        conteo = resDecay.rows[0].conteo_rafaga + 1;
      } else {
        conteo = 1; // Reinicio por enfriamiento cumplido
      }
    }

    // Upsert contador de ráfaga
    await client.query(
      "INSERT INTO user_action_decay (usuario_id, accion, conteo_rafaga, ultimo_evento) " +
      "VALUES ($1, $2, $3, NOW()) " +
      "ON CONFLICT (usuario_id, accion) DO UPDATE SET conteo_rafaga = $3, ultimo_evento = NOW()",
      [usuarioId, accion, conteo]
    );

    // Calculo del factor decay con exponente alpha
    if (conteo >= conf.kMax) {
      factorDecay = 0.0;
    } else {
      var ratio = (conteo - 1) / (conf.kMax - 1);
      factorDecay = Math.max(0.0, 1.0 - Math.pow(ratio, conf.alpha));
    }
  }

  var mNivel = obtenerMultiplicadorNivel(nivelUsuario);
  var xpFinal = Math.round(xpBase * mNivel * factorDecay);

  return {
    xpOtorgada: xpFinal,
    factorDecay: factorDecay,
    multiplicadorNivel: mNivel
  };
}

5. Ventajas del Modelo v2.0 para ExploraCO
Hiper-Incentivo de Progresión: Al subir de nivel, realizar la misma acción llega a rendir hasta 3 veces más XP (x3.0) en Nivel 20, convirtiendo la subida de nivel en el activo más valioso del juego.

Defensa de la Base de Datos: El decaimiento progresivo (Rising Star Decay) inhabilita granjas de clics o votaciones masivas desmedidas, obligando al usuario a explorar el mapa y participar en distintas actividades.

Sostenibilidad del Mapa Vivo: Alinea la economía del juego con el negocio: proponer lugares, verificar datos en terreno y organizar planes comunitarios son ahora las acciones que otorgan mayor XP.
